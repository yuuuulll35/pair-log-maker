# 페어 로그 메이커 (pair-log-maker)

레트로 윈도우 UI 스타일의 **커플/페어 캐릭터 카드 메이커**. 브라우저에서 바로 편집하고 PNG로 저장합니다.

## 사용법

[페이지 열기](https://yuuuulll35.github.io/pair-log-maker/) — 설치 없이 바로 사용합니다.

또는 `index.html`을 내려받아 브라우저로 열면 오프라인에서도 동작합니다.

## 기능

- **인라인 편집** — 카드의 모든 문구를 클릭해서 바로 수정
- **성향 그래프** — 4개 사분면 차트, 점을 드래그해 두 캐릭터의 성향 배치
- **체크리스트 · 타임라인 · 세계관 · 시점** — 항목별 on/off
- **이미지** — 사진 업로드 후 Cropper.js로 자르기, 꾸밈 스티커 자유 배치
- **마우스 포인터 장식** — 위치·크기 조절, on/off
- **테마** — 캐릭터 색상 2종, 배경(체커/단색/그라데이션/이미지) 선택
- **저장** — 작업 상태는 브라우저에 자동 저장. 작업본을 HTML 파일로 내보내고 다시 불러올 수 있음
- **PNG 내보내기** — 2~4배 고해상도. 카드가 길면 브라우저 캔버스 한계(16384px)에 맞춰 배율을 자동 조정해 잘림을 방지

## 구성

`index.html` 한 파일에 마크업·스타일·스크립트가 모두 들어 있습니다. 빌드 과정이 없습니다.

외부 의존성은 CDN에서 불러오는 두 가지입니다.

- [Cropper.js](https://github.com/fengyuanchen/cropperjs) — 이미지 자르기
- [html-to-image](https://github.com/bubkoo/html-to-image) — PNG 내보내기

두 라이브러리 모두 MIT 라이선스입니다.
